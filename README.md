# Klinik Pratama Asih – Sistem Laporan Keuangan

Versi siap diunggah ke GitHub Pages.

## Struktur
- `index.html`
- `js/app.js`
- `js/charts.js`
- `js/db.js`
- `js/export.js`
- `css/styles.css`
- `img/logo-klinik-asih.svg`

## GitHub Pages
1. Buat repository GitHub baru.
2. Upload seluruh isi folder ini, bukan folder induknya.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch** → branch `main` → folder `/ (root)`.
5. Simpan dan tunggu proses deployment selesai.

Aplikasi menggunakan LocalStorage sebagai penyimpanan lokal browser. Backend API tidak diperlukan untuk menjalankan versi GitHub Pages ini.
